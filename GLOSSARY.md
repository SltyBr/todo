# Todo

A personal todo list for one person's daily use, on phone and desktop.

## Language

**Todo**:
A single thing the user intends to do, with a Title, an optional Description, and a Completed state.
_Avoid_: Task, item, note, entry

**Title**:
The short, required one-line name of a Todo.
_Avoid_: Text, name, label

**Description**:
Optional free-form detail attached to a Todo, kept as plain text with line breaks.
_Avoid_: Notes, body, details

**Completed**:
The state of a Todo the user has marked as finished. A Todo that is not Completed is **Active**.
_Avoid_: Done, checked, finished, pending

**Filter**:
The view choice that limits the visible Todos to All, Active, or Completed.
_Avoid_: Tab, view, mode

**Clear completed**:
The action that removes every Completed Todo at once.
_Avoid_: Archive, purge
